# Module 03.3 - Fact-checking, Misinformation & Digital Footprints 🌐🔍

## 📖 Description
An interactive, web-based presentation designed to educate students on evaluating digital content. It covers crucial topics such as identifying misinformation, the step-by-step fact-checking process, and understanding digital footprints. 

Built specifically for modern classrooms, this single-file presentation scales perfectly up to 86" Smart Boards and supports interactive click and keyboard navigation to keep students engaged.

## ✨ Features
- **Interactive Animations:** Step-by-step visual guides explaining the spread of fake news and digital data collection.
- **Fully Responsive:** Scales seamlessly from mobile screens to massive 4K/8K Smart Boards using dynamic CSS scaling.
- **Zero Dependencies:** Built with pure HTML, CSS, and Vanilla JavaScript. No frameworks, servers, or installations required.
- **Easy Navigation:** Progress through interactive steps and slides using Mouse Clicks, `Spacebar`, or `Arrow Keys`.
- **Dark Mode UI:** Designed with a modern, eye-friendly dark theme and glowing network nodes.

## 🚀 How to Use
1. Clone this repository or download the HTML file.
2. Double-click the file to open it in any modern web browser (Google Chrome, Firefox, Edge, Safari).
3. Click anywhere on the screen, or use the `Right Arrow` / `Spacebar` to advance through the presentation steps.
4. Use the `Left Arrow` to go back to the previous slide.

## 🛠️ Technologies Used
- **HTML5** (Semantic structure)
- **CSS3** (Custom properties, Keyframe Animations, Flexbox, Responsive UI)
- **Vanilla JavaScript** (DOM manipulation, Event handling, State management)
